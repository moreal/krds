# 네이티브 예제 {#native-examples}

각 구현은 자기 픽스처와 Storybook을 소유합니다. 안정 네이티브 대상 7개 모두 웹 항목 54개를 매핑하는 컴파일러 체크포인트가 있습니다. 소스 해시와 원본 컴파일러 근거를 검증합니다. 소스가 바뀌면 문서 빌드에서 체크포인트가 무효가 됩니다. 체크포인트 범위는 최신 네이티브 후보, 동작 인수, 릴리스 준비와 별개입니다.

## 로컬 네이티브 미리보기 {#local-native-previews}

각 프레임워크는 자기 `docs-preview` 아티팩트를 빌드합니다. 문서 빌드는 이 아티팩트를 검증해 `/krds/previews/<framework>/`에 조립합니다. 이 사이트가 게시하는 트리와 같습니다. 문서를 빌드한 뒤 `node apps/docs/scripts/serve.mjs`를 실행하면 조립된 `/krds/` 트리를 로컬에서 제공합니다. 이 서버는 네이티브 앱을 다시 빌드하지 않습니다. 픽스처나 Storybook 서버로 리디렉션하지 않습니다. 없는 출력을 만들어 내지도 않습니다. 없는 파일에는 명시적인 404를 반환합니다.
