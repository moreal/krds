# Qwik compatibility

The six native pilots (`Button`, `NativeSelect`, `Modal`, `Tabs`, `Calendar`, `DateInput`) and `KrdsProvider` are implemented using Qwik `component$`, signals and QRL callbacks. The supported evidence baseline is the selected Qwik **1.20.3**, optimizer **1.20.3**, Vite **7.3.1**, Node **24.18.0** and Yarn **4.14.1**. This evidence does not establish other Qwik versions or the full KRDS catalog.

The public callback props are `onValueChange$`, `onOpenChange$`, `onConfirm$` and `onCancel$`; Button uses native `onClick$`. Controlled props remain authoritative, reset adds no user-change notification, and DateInput keeps raw text separate from its canonical successful hidden values. Invalid or uncommitted differing drafts block native submission. The component does not recursively submit a form. Dates are strict Gregorian ASCII ISO strings with explicit reference dates.

`KrdsProvider` supplies Korean/English locale and LTR/RTL direction. Browser resources use their owning DOM document. No DOM access occurs at package import. Transient modal isolation is excluded with `noSerialize`, rebuilt at document-ready and cleaned on actual close/unmount. A small SSR sync `qinit` default guard preserves first-key cancellation in Qwik 1.20.3 without eagerly rendering the app. All enabled tabs and calendar dates remain sequential keyboard stops.

The production consumer imports the built package export, produces actual paused SSR with the official client manifest, and serves it through request-time production rendering. Cold first clicks/keys/inputs, controlled rejection, native form/IME/reset behavior and modal cleanup pass alongside canonical Chromium/WebKit tests. Downloads and executed functions are recorded separately; retained server JSON is not presented as a fresh post-interaction serialization.

Native siheom passes **6/6**; common canonical contracts pass **10/10 per browser**; extended native behavior passes **18/18 per browser**; production resume passes **14/14** and invalid configuration checks pass **7/7**. Six native Storybook cases have zero raw axe findings and zero external-request findings. The normal, narrow, 200% zoom, forced-colors, invalid and representative story images were opened and inspected.
