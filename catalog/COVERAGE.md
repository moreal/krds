`node tools/check-coverage.mjs` is a fail-closed release gate. `verify:catalog` only checks frozen inventory/source integrity and evidence paths. Until every stable pair is independently verified, the coverage gate exits 1. Never fill metadata from build success, an empty suite, an aggregate without raw tests, an unsupported adapter or a probe.

Each `coverage.json` stable row promoted to `verified` needs `verification` with:

- `componentId`, `framework`, `nativeRenderer` matching the row; `profile: "stable"`, `status: "accepted"`, `candidate: false`.
- `fileHashes` binds every referenced spec/docs/review/native/story source, executed behavior/story/check report, native check log and screenshot to its exact SHA-256. Stale code or evidence invalidates acceptance.
- `sourceSha256`, `specPath`, `docsPath`, `reviewPath`; and `reviewAcceptance` containing `componentId`, `framework`, `status: "approved"`, `independent: true`, reviewer identity and zero `critical`/`important` open findings. This metadata records actual controller-owned independent review, never self-approval.
- Nonempty `nativeSourcePaths` under the same native package and `storySourcePaths` under that framework's native Storybook source. Evidence paths must exist and stay inside the repository; probes/foreign renderers cannot substitute.
- File-backed raw attachments (including native-health JSON) require safe repository resolution and their own accepted `fileHashes` entry before loading/parsing; an inline body remains protected by its raw-report hash. Every referenced external attachment is checked, not only its filename.
- `publicApi` binds the exact catalog `exportName`, package name, actual `packageJsonPath` exports map, selected public `entryPoint`/`importSpecifier`, built `runtimeEntryPath`/`typesEntryPath`, public source entry paths and built artifact paths. The value export must actually exist through relative built re-export chains in JS and declarations. An internal unexported file is insufficient. `consumerWorkspacePath` and `consumerSourcePaths` identify an existing same-framework fixture/Storybook/package workspace, with a direct adapter dependency and a real used named public value import. Its hash-bound `public-api-consumer` report/log must bind matching paths/identities, actual runtime import, successful example/type compile, command, observations and exit 0. This is an in-workspace public API gate; the separate outside-package T14 consumer remains later and is not a prerequisite cycle.
- `behavior: {caseIds, reportPath, rawPath}`: all exact required cases; actual contract runner report plus raw Playwright JSON. Every `${framework} ${componentId}/${caseId}` must execute and pass, with matching `native-health.json` attachment contents, no skipped/empty tests and no raw runner errors.
- `stories: {storyIds, reportPath, screenshotDirectory}`: all exact native IDs; actual Storybook render/request/accessibility results, zero request/axe violations and per-story PNG evidence.
- `checks: [{kind, reportPath}]`: real executed typecheck, build and visual checks, Lit Shadow DOM, Qwik first lazy event, Angular partial APF and CVA/form/reset for form controls, required human accessibility review for media/hidden content, and actual local-asset/provenance review where applicable. Each report binds component/framework/kind, `status: "passed"`, `executed: true`, `exitCode: 0`, the actual `command`, nonempty `observations` and existing nonempty `logPath`.

Gate unit tests create complete synthetic evidence only in disposable temporary directories. Their positive fixture is not repository/native coverage. Negative tests reject missing/wrong frameworks, unauthorized N/A, unsupported verification, zero/skipped/raw-health mismatches, missing stories, foreign sources, absent native checks and stale source hashes.
