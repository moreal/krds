# 컴포넌트 목록 {#component-catalog}

KRDS 웹 컴포넌트 54개입니다. 검색(Ctrl/Cmd+K)으로 영문 이름, 한국어 이름, API, 키보드 안내를 찾을 수 있습니다. 스플래시 화면(Splash screen)은 플랫폼 전용이라 제외합니다.

프레임워크별 지원 상태는 각 컴포넌트 페이지에 있습니다. Solid 2는 별도 미리보기입니다.
