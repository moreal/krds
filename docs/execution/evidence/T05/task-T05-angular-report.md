## Scope and implementation

- Official Angular CLI `@angular/build:application` production fixture, standalone native Angular components, native signals and inputs/outputs. The fixture consumes the built public `@krds-native/angular` export and built `@krds-native/test-contracts/driver` export, with no source aliases or foreign renderer.

Every canonical route mounts healthy native status and protocol-1 Angular bridge, then explicitly reports `Component not implemented: <component>/<case>`. Destroying the Angular fixture unsubscribes and disposes the bridge.
- Actual published `@siheom/angular` adapter used through `given.render`, `actions.click`, `assertions.textContent` and `assertions.focused`. Smoke covers 0→1, controlled count/label update to 7, next click to 8, and real TestBed destruction/DOM removal. Separate tests distinguish synthetic adapter input from a trusted Playwright provider click.
- Official `@storybook/angular:build-storybook` integration produces `dist/index.json` and `dist/iframe.html`. Three native stories map serializable shared infrastructure state to native Angular inputs. No story play, loader, API, auth, external images/fonts or remote assets. Locally bundled Storybook assets/fonts are permitted and pass the request gate.
- App scripts and Nx targets use the shared selected-framework runners without a recursive root/Nx loop. Default suites exclude probes and fail when canonical cases are missing; Vitest explicitly has `passWithNoTests: false`. Nx contract/siheom/stories targets are uncached and declare build prerequisites, inheriting the shared manifest/scenario inputs.

## Resolved issues and rulings

- Shared Vitest startup initially lacked Vite in a pnpm-linked transitive peer context. The designated root owner repaired and verified peer forwarding; this owner performed no installation or shared edits. Initial startup evidence is `siheom-red.log`.
- Published Testing Library Angular 19.6.0 has no public `cleanup` export. Native cleanup uses official `TestBed.resetTestingModule`, and globals enable the installed library's documented automatic afterEach cleanup. Actual DOM removal is asserted.
- Vite 8 does not itself lower Angular's legacy decorator syntax. A test-only pre-transform invokes directly declared TypeScript 6.0.2 `transpileModule` with experimental decorators before official Angular JIT TestBed. Production rendering/build stays the official Angular CLI application builder. Cost if incorrect: native tests could diverge from AOT behavior; production build plus independent production browser probe are separately verified.
- Vitest 4 replaces `api.port=0` with a fixed default. The native config reserves an OS-selected loopback port first and passes the resulting port, with fallback handling retained by Vitest. Failure artifacts use per-process directories. Cost if incorrect: a narrow port-release race could trigger Vitest's normal alternate-port selection; no fixed shared server is assumed.
- Storybook's framework path is resolved from the consuming app using `createRequire`, preventing preset lookup from relying on hoisted packages. The root owner separately repaired the published shared Storybook resolver's missing Angular peer visibility.
- Official Storybook's Compodoc default attempted an undeclared optional documentation executable. `compodoc: false` uses the installed official builder schema; no documentation addon or generated docs are used by these infrastructure stories.
- Actual production-story execution caught an inherited `noEmit: true` setting that created an empty CSF JavaScript chunk despite a valid story index. Storybook tsconfig now emits during the official build, while its typecheck retains `--noEmit`. Rebuild plus real 3/3 browser execution verifies the fix. Failed-run evidence: `test-results/t05/stories-1793321975586-81591-8337d43f/report.json` and `story-debug.log`.
- Storybook reports large preview/entrypoint warnings (about 2.15 MiB, including Angular compiler). These are infrastructure build warnings and do not block rendering. No release-size claim is made.

No unresolved infrastructure blocker remains.
