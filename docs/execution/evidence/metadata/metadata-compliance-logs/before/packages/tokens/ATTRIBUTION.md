# 출처 및 이용 조건

이 프로젝트는 행정안전부가 공공누리 제1유형으로 제공하는 KRDS(Korea Design System)의 디자인 지침과 자료를 활용한 독립적인 구현입니다. 원문과 리소스는 [KRDS 공식 홈페이지](https://www.krds.go.kr/)에서 확인할 수 있습니다. 사용한 자료의 버전, 원본 경로와 변경 내용은 함께 제공하는 `provenance.json`과 `THIRD-PARTY-NOTICES.md`에 기록합니다.

이 프로젝트의 명칭과 배포는 정부 또는 KRDS 운영기관의 공식 배포물, 후원, 인증 또는 보증을 의미하지 않습니다. 기관의 로고·명칭·공식 배너 신원은 소비자가 실제 권한과 서비스 맥락에 맞게 제공해야 합니다. 이 패키지는 기관 로고나 정부 신원 자산을 제공하지 않습니다.

프로젝트가 독자적으로 작성하여 권리를 보유한 코드에는 MIT License를 적용할 계획이며, 실제 저작권자는 아직 확정되지 않았습니다. KRDS 원본 및 가공 자료, 제3자 코드와 폰트에는 각각 명시된 조건이 적용되며, 프로젝트의 MIT 적용 계획이 이를 대체하지 않습니다. 미확정 프로젝트 신원은 릴리스 차단 사유입니다.

KRDS 기준선은 HTML Component Kit 1.1.0, commit `d6bb184c823e4757f05807ea4646a23e3133b6e6`입니다. 웹 지침은 저장소 릴리스와 별도로 2026-10-30에 수집한 원문의 SHA-256으로 식별합니다. 공식 정책의 출처표시 예시는 행정안전부가 2024년에 제작한 KRDS를 가리키지만, 개별 파일에 없는 저작권 연도·표시를 추정하여 생성하지 않습니다.

KRDS 자료를 재배포하는 경우 이 출처 목록과 패키지의 `LICENSES/`에 보존한 정책 전문, 사용 자료의 변경 기록을 함께 전달하십시오. 이 안내는 모든 소비 앱 화면 footer에 항상 문구를 표시해야 한다는 별도 의무를 만들지 않습니다. 원문 조건은 [KRDS 저작권 정책](https://www.krds.go.kr/html/eng/utility/utility_05.html)과 [공공누리 이용 조건](https://www.kogl.or.kr/info/license.do)을 확인하십시오.
