# @krds-native/assets

Eight unmodified generic KRDS SVG icons are available as local files through `@krds-native/assets/icons/*.svg` or as URLs through `krdsIconUrls`. No remote fetch is required. Provide accessible labels in the consuming control; decorative images should have empty alternative text.

Institution logos, service names, official government banners and third-party brand marks are not bundled. Consumers supply their own identity and verify their rights. `InstitutionIdentity` describes optional consumer-provided identity without inventing an institution.

The icons retain the recorded KRDS KOGL Type 1 conditions. See LICENSE.md, ATTRIBUTION.md, THIRD-PARTY-NOTICES.md, provenance.json and LICENSES/. Preserve these notices when redistributing the icons.
