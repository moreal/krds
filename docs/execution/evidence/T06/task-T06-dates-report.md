The exact mode-specific values/callback details follow shared `DateRangeValue` and `ValueChangeDetails`. Both components support single/range state, min/max/referenceDate/today, locales and partial translation dictionaries. Calendar additionally supports required coordination for DateInput, complete weekday/month translation arrays, endpoint translations, onConfirm/onCancel. DateInput supports optional `calendarTranslations`, external `invalid`/`errorMessage` (`error` is also accepted), and `returnFocusId` for an explicit missing-opener fallback. An available trigger always wins over the fallback. Lead owns index exports and fixture configuration.

Calendar is a real native Solid table and native date/navigation/footer buttons. All enabled dates remain sequentially tabbable; arrows/Home/End/month/year keys add focus-only navigation. Range selection is tentative until Confirm and has endpoint/interior state attributes independent of focus styling. DateInput is a text draft editor with named hidden canonical form values, native custom validity, form submit/reset listeners, and no timestamp/host-timezone parsing. Popup lifetime uses a native `<dialog>.showModal()` to preserve the separate Calendar selected-date initial-focus contract without altering generic Modal's dialog/first-interactive policy.
