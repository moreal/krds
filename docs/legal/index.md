# Sources, rights and redistribution

KRDS Native is an independent implementation. It is not an official KRDS or government service and does not claim government affiliation. Repository metadata is `https://github.com/moreal/krds`; the selected package scope is `@unofficial-krds`. Account ownership remains unverified, and publication, pushing and tagging are unauthorized.

The <a href="../_legal/index.html" target="_self">local distribution inventory</a> identifies the files actually included in this documentation artifact, their snapshot hashes, original terms and separate attribution.

## Official KRDS material

The provider attribution recorded by this project is **행정안전부 / Ministry of the Interior and Safety — KRDS source materials under their verified original terms**. The original [KRDS repository](https://github.com/KRDS-uiux/krds-uiux) and the [official English copyright policy](https://www.krds.go.kr/html/eng/utility/utility_05.html) remain separate from this project. The [KOGL license policy](https://www.kogl.or.kr/info/license.do) explains the original public-license conditions; the project's `LicenseRef-KRDS-KOGL-Type-1` is a local reference, not an official SPDX identifier or a dual-license election with conflicting ISC package metadata.

The [preserved policy bytes and hashes](https://github.com/moreal/krds/blob/main/compliance/license-policy.json) and [provenance records](https://github.com/moreal/krds/blob/main/compliance/provenance.json) identify which materials have verified rights. Do not treat a website footer, generic policy or repository metadata as clearance for every institutional identity, trademark, image, guide diagram or external asset.

Preserved original terms are available locally with this documentation: [KRDS copyright policy](https://github.com/moreal/krds/blob/main/LICENSES/KRDS-copyright-en.html), [KOGL policy](https://github.com/moreal/krds/blob/main/LICENSES/KOGL-license-policy.html), and [Pretendard GOV OFL 1.1](https://github.com/moreal/krds/blob/main/LICENSES/Pretendard-GOV-OFL-1.1.txt). These are unchanged source texts, served as plain text so original HTML is never executed as a documentation page.

Each component page identifies its official detail URL, frozen baseline, retrieval time and SHA-256. Website snapshots are distinct from the kit tag. Quoted or derived guidance retains its original KRDS rights. Original KRDS JavaScript is reference evidence; it must not run alongside a native state owner controlling the same DOM.

## Fonts, dependencies and local media

Pretendard GOV font bytes retain their own OFL license, attribution and source lineage. This site loads the original local Pretendard GOV Regular, Medium and Bold files, with a sans-serif fallback. Its independent monochrome wordmark and K icon are outlined artwork made using Pretendard GOV; this does not relicense the original font software or imply government endorsement. Dependencies retain their original licenses and notices. Keep the package's `LICENSE.md`, `LICENSES/`, `ATTRIBUTION.md`, `THIRD-PARTY-NOTICES.md` and `provenance.json` with the relevant redistributed bytes.

Only the specifically cleared local mathematical tone, geometric video and VTT fixtures may be used for the current media demonstrations. No Yuna recording is cleared by this work. A local asset's presence is not sufficient proof of redistribution permission; use the actual asset-source record and hash.
