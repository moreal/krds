# @unofficial-krds/fonts

This package contains the official, unmodified full Pretendard GOV Regular (400), Medium (500), and Bold (700) WOFF2 files. Import `@unofficial-krds/fonts/fonts.css` to opt in, or use the local URLs exported by `pretendardGovFontUrls`. The stylesheet contains local relative URLs and never requests a CDN. No custom subset, glyph removal, format conversion, metadata edit or renaming was performed.

The original SIL OFL 1.1, copyright notices and Reserved Font Names `Pretendard GOV`, `Source`, `Inter` and `M PLUS 1` are preserved in LICENSES/Pretendard-GOV-OFL-1.1.txt. Preserve the full text and notices with redistributed font files. OFL restricts selling fonts by themselves; embedding them in an application does not put independent UI code under OFL. Modified fonts require separate consideration of the original RFN conditions.
